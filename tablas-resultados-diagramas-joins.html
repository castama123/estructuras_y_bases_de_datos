5. FULL OUTER JOIN (simulado) — usuarios + reproducciones

Consulta: listar el nombre de cada usuario junto con el id de cada canción que reprodujo, trayendo también los usuarios sin reproducciones y las reproducciones sin usuario.

SELECT u.nombre, r.id_cancion FROM tbl_usuarios u LEFT JOIN tbl_reproducciones r ON u.idusuario = r.id_usuario UNION SELECT u.nombre, r.id_cancion FROM tbl_usuarios u RIGHT JOIN tbl_reproducciones r ON u.idusuario = r.id_usuario;

Con estos datos, el resultado es idéntico a la tabla del LEFT JOIN de arriba (11 filas): como toda reproducción tiene un id_usuario obligatorio, nunca hay una reproducción huérfana del lado derecho que agregar.

7. SELF JOIN — canciones del mismo género

Consulta: listar todos los pares de canciones que comparten el mismo género, sin repetir pares ni comparar una canción consigo misma.

SELECT a.titulo AS cancion_1, b.titulo AS cancion_2, a.genero FROM tbl_canciones a JOIN tbl_canciones b ON a.genero = b.genero AND a.id_cancion < b.id_cancion ORDER BY a.genero, a.titulo;
