¿Qué es una base de datos?

Una base de datos es un sistema organizado para guardar información de forma persistente: sobrevive aunque se apague el computador o se reinicie la aplicación. Se diferencia de una estructura de datos en memoria (como un diccionario o una lista en Python) en que esta última vive solo mientras el programa está corriendo. Un motor de base de datos (o DBMS, Database Management System) es el software que administra esa información: la guarda, la organiza, la protege y responde a las consultas que le hacemos.

Tipos de motores de bases de datos

Relacional (SQL)

Organiza la información en tablas con filas y columnas. Prioriza la consistencia: ideal para dinero, inventarios y cualquier dato que no pueda quedar a medias (MySQL, PostgreSQL).

Documental (NoSQL)

Guarda documentos tipo JSON, sin un esquema rígido. Cada registro puede tener campos distintos. Útil para catálogos y perfiles muy variables (MongoDB).

Clave-valor

La forma más simple: cada dato se busca por una llave única. Extremadamente rápida porque vive en memoria RAM. Ideal para caché y sesiones (Redis).

Grafos

Modela la información como nodos y relaciones (aristas). Perfecta para redes sociales, recomendaciones y cualquier dato donde lo importante son las conexiones.

Vectorial

Guarda información como vectores numéricos que representan significado. Es la base de la búsqueda semántica y la Inteligencia Artificial generativa.

Columnar

Optimizada para leer millones de filas de pocas columnas a la vez. Se usa en analítica y reportes masivos (BigQuery, Cassandra).

SQL vs. NoSQL: ¿cuándo usar cada uno?

SQL (Relacional) NoSQL
EstructuraEsquema fijo, tablas con filas y columnasEsquema flexible, documentos o pares clave-valor
PrioridadConsistencia e integridad (ACID)Velocidad y escalabilidad horizontal
RelacionesExplícitas, con llaves foráneasGeneralmente embebidas dentro del mismo documento
Ejemplo de usoPagos, facturación, inventariosCatálogos variables, logs, caché, sesiones

Vocabulario esencial

Tabla

Colección de datos organizados en filas y columnas, todos de la misma entidad (por ejemplo, todos los usuarios).

Registro / Fila

Una instancia individual dentro de la tabla: un usuario específico, con todos sus datos.

Columna / Atributo

Una característica que describe a cada registro, con un tipo de dato definido (texto, número, fecha).

Llave primaria (PK)

El identificador único de cada fila. Ninguna otra fila puede tener el mismo valor.

Llave foránea (FK)

Un campo que apunta a la PK de otra tabla, creando una relación entre ambas.

Esquema

El "plano" que define qué tablas existen, qué columnas tiene cada una y cómo se relacionan.

Índice

Una estructura auxiliar que acelera la búsqueda, como el índice de un libro.

Consulta (Query)

Una instrucción para pedirle datos al motor: buscar, insertar, modificar o borrar información.
